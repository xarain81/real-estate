# Reel Estate Singapore

A demo website showing how an AI voice and text assistant can help prospective buyers explore Singapore properties.

## Why this website exists

Real estate agents spend significant time answering repetitive questions about listings, while buyers often expect immediate answers. This demo explores whether an AI property assistant can improve responsiveness and reduce routine interruptions.

## How it works

Visitors can browse and filter sample properties, open listing details, and chat or speak with John, an ElevenLabs AI property assistant. The assistant uses a property knowledge base and guided conversation flow to answer questions, recommend properties, and collect follow-up details.

## High-level findings

- The assistant can handle a property enquiry from greeting through recommendation and follow-up.
- A focused knowledge base helps keep answers grounded in the available listings.
- The agent can extract useful lead information such as name, phone number, and email.
- The demo still needs stronger property data, calendar integration, and safeguards against inaccurate answers.

This is a demonstration using sample data; responses may contain inaccuracies.
