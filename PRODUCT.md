# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React and Vite, implemented as a standalone app within the existing repository.

## Users

Singapore property seekers who want a conversational way to explore homes, neighbourhoods, and lifestyle fit.

## Product Purpose

Reel Estate Singapore is a consumer-facing demonstration of an ElevenLabs property assistant. Success means a visitor immediately understands the property-discovery proposition, can browse and filter representative homes, can start a text or voice conversation, and can inspect how the demo was designed and validated.

## Positioning

The page connects a concise luxury-residential hero to a focused property edit, then makes a live multimodal conversational assistant the next step in discovery before exposing the project thinking.

## Operating Context

Visitors use the one-page website on desktop or mobile, move from the property hero into a filterable five-home edit, inspect a listing in a focused details dialog, continue to the embedded assistant by text or voice, and then read the project story.

## Capabilities and Constraints

- The official ElevenLabs conversational widget supplies text and voice interaction.
- Five static Singapore condominium records support district and bedroom filtering plus transient detail views.
- The agent must be public, have authentication disabled, enable Voice + Text, and use an allowed-domain list.
- Only the public agent ID may be present in the client; ElevenLabs API keys must never enter the website.
- The five project-story topics remain editable placeholders until real project evidence is supplied.
- Delivery is local-only; publishing and production-domain configuration are outside the current scope.

## Brand Commitments

- Product name: Reel Estate Singapore.
- Consumer-facing, professional, restrained voice.
- The supplied Horizon Estate screenshot is style direction only.
- The approved concepts use a true-white editorial layout, near-black type, thin neutral rules, a restrained verdant accent, and original Singapore luxury-residential imagery.

## Evidence on Hand

- A configured ElevenLabs agent exists but still needs widget access, multimodality, branding, and allowed-domain setup.
- Two approved visual concepts define the hero/widget and project-story layouts.
- A supplied property-listing reference provides five authoritative mock records and their residential photography.
- No additional business metrics, testimonials, property inventory, integration claims, or project lessons are available and none may be fabricated.

## Product Principles

- Use the representative property edit to bridge the opening proposition and the live assistant.
- Put the live assistant before the case study.
- Make the visitor’s next action unmistakable.
- Keep provider-controlled widget behavior honest.
- Prefer real demonstrations and editable placeholders to invented claims.
- Preserve accessibility and responsive clarity.

## Accessibility & Inclusion

Use semantic landmarks, keyboard-visible focus, sufficient colour contrast, reduced-motion support, descriptive image alternatives, and layouts that remain usable at mobile widths and browser zoom.
